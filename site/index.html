How it works

Check one logical effect per idempotency key

  1. 1

    Define synthetic deliveries

    List the original event, retry, delay, or reorder case you need to test.

  2. 2

    Run your handler locally

    Use an in-process function or a loopback HTTP endpoint in test wiring.

  3. 3

    Inspect the report

    Fail the test when an adapter records more than one expected effect.

Install

Add the rehearsal to an integration test

Use the package with synthetic IDs. The report records effect identity, not payload values.

terminal
npm install --save-dev idempotency-rehearsal

import { defineScenario, runScenario } from 'idempotency-rehearsal';

Safety and limits

Use it for local tests, not delivery infrastructure

It checks declared sequences. It does not run a webhook gateway, queue, or production event store.
